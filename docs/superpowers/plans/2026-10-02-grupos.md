# Grupos de amigos: cuentas, visibilidad y recuperación — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que grupos de amigos compartan salidas del diario sin exponerlas al resto, con cuentas anónimas por dispositivo y código de recuperación para cambiar de móvil.

**Architecture:** Sesión anónima de Supabase (`signInAnonymously`) + tabla `perfiles` con el hash de un código de recuperación. Las tablas `salidas`/`fotos` pasan a ser solo del dueño; los miembros leen lo compartido por funciones `security definer` que anulan las coordenadas cuando se comparte «solo la zona». Las fotos pasan a un bucket privado con URLs firmadas. Las pruebas de la base de datos corren en un Postgres desechable en Docker que imita a Supabase.

**Tech Stack:** PostgreSQL (migraciones de Supabase, RLS, funciones plpgsql), Supabase Auth anónima, `@supabase/supabase-js` 2.117.2 (CDN), JavaScript vanilla ES modules, `node --test`, Docker (`postgres:17-alpine`).

**Spec:** `docs/superpowers/specs/2026-10-02-grupos-design.md` (las desviaciones respecto a ella están en «Decisiones de implementación» y se vuelcan a la spec en la Tarea 0).

## Global Constraints

- `MAX_MIEMBROS_GRUPO = 20`: constante única en SQL (`public.max_miembros_grupo()`) y reflejada en `MAX_MIEMBROS` de `js/grupos.js`.
- Código de recuperación: 16 caracteres, alfabeto Crockford base32 (`0-9 A-Z` sin `I L O U`, ~80 bits), mostrado `XXXX-XXXX-XXXX-XXXX`, solo se guarda su hash SHA-256.
- Código de invitación de grupo: 8 caracteres del mismo alfabeto.
- La entrada sigue sin correo ni contraseña. No hay pestaña nueva en la barra: `#grupos` y `#unirse/CODIGO` cuelgan de «Diario» (`SECCION` en `js/app.js`).
- Migraciones nuevas con sello de tiempo mayor que las existentes (la última de main al planificar es `20261004000000_lluvia_dia`; las de grupos usan `20261005…` y la de cierre `20261006…`); nunca se edita una ya aplicada. La que cierra el acceso abierto vive en `supabase/pendientes/` hasta el despliegue.
- Zonas, sitios, índice, mapa y meteo siguen siendo públicos. `ajustes_umbrales` no cambia.
- Interfaz y mensajes en español; sin `innerHTML` con datos (usar `el()` de `js/ui/dom.js`); versión fijada de supabase-js 2.117.2.
- Nunca afirmar comestibilidad; esta fase no toca identificación.
- `npm run comprobar` (207 pruebas + validador) debe seguir pasando; las pruebas SQL van aparte en `npm run probar:sql` (necesitan Docker).
- Cada commit termina con la línea `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Decisiones de implementación (desviaciones de la spec)

1. **Rutas de fotos sin cambiar** (`<salida_id>/<n>.jpg`): el permiso se decide consultando de quién es la salida (`puede_ver_foto`, `es_mi_salida`), no por una carpeta con el id del dueño. Así el traspaso de cuenta no obliga a mover ficheros y no hay que migrar las fotos existentes.
2. **Enlace de invitación:** `…/setas/#unirse/CODIGO` (no `#unirse=CODIGO`), porque el router parte el hash por `/`.
3. **`salida_grupos` solo se escribe con la función `compartir_salida`** (atómica, comprueba dueño y pertenencia); la tabla solo se lee.
4. **Punto abierto de la spec resuelto:** con «solo la zona» el servidor devuelve `meteo = null` y quita `punto` del `indice` (el id del punto de la zona acota la ubicación).
5. **Cierre del acceso abierto** en `supabase/pendientes/20261006000000_cerrar_acceso_abierto.sql`, con un guardia que aborta si queda alguna salida sin dueño.
6. **Reclamo de las salidas antiguas** por nombre de autor (`reclamar_salidas`), sin secreto: la ventana es de minutos y solo hay dos personas; se reclama el mismo día del despliegue y el guardia de la decisión 5 comprueba que no quede nada.

## Review Focus

Entradas o condiciones que la spec implica pero ninguna tarea de comportamiento cubre de forma obvia; cada línea tiene su prueba en la tarea indicada.

1. **Primer arranque sin red:** no se puede comprobar el perfil; la app no debe ofrecer «Crear perfil» (crearía un duplicado) sino pedir conexión. → Tarea 6 (`cargarPerfil` propaga el error de red).
2. **Borrador compartido con un grupo del que ya te echaron:** debe subirse como privado, no quedarse atascado en la cola. → Tarea 8.
3. **Código de grupo o de recuperación mal escrito** (minúsculas, espacios, guiones, `O` por `0`, `I`/`L` por `1`). → Tareas 2, 3 (SQL) y 6, 7 (cliente).
4. **El único administrador intenta salir** con más miembros dentro; y el último miembro que sale. → Tarea 3.
5. **«Solo la zona» no debe filtrar el punto** por `lat`, `lon`, `meteo` ni `indice.punto`; ni siquiera una salida compartida a dos grupos con precisión distinta. → Tarea 4.
6. **Reclamar salidas dos veces / con otro nombre / sin perfil**, y salidas antiguas sin nombre de autor. → Tarea 4.
7. **Recuperar cuenta desde una sesión que ya tiene perfil** y fuerza bruta del código (límite de intentos). → Tarea 2.

-- Entorno mínimo que imita a Supabase: roles, auth.uid(), extensions, un storage simplificado y ayudas de prueba.
create role anon nologin;
create role authenticated nologin;
create role service_role nologin bypassrls;

create schema auth;
create function auth.uid() returns uuid language sql stable
as $$ select nullif(current_setting('request.jwt.claim.sub', true), '')::uuid $$;

create schema extensions;
create extension pgcrypto schema extensions;

grant usage on schema public, auth, extensions to anon, authenticated, service_role;
grant execute on function auth.uid() to anon, authenticated, service_role;
-- Supabase concede todo en `public` a estos roles por defecto: las migraciones revocan lo que haga falta.
alter default privileges in schema public grant all on tables to anon, authenticated, service_role;
alter default privileges in schema public grant all on sequences to anon, authenticated, service_role;
alter default privileges in schema public grant execute on functions to anon, authenticated, service_role;

create schema storage;
grant usage on schema storage to anon, authenticated, service_role;
create table storage.buckets (
  id text primary key, name text, public boolean not null default false,
  file_size_limit bigint, allowed_mime_types text[]
);
create table storage.objects (
  id uuid primary key default gen_random_uuid(),
  bucket_id text references storage.buckets (id), name text not null, owner uuid
);
alter table storage.objects enable row level security;
grant select, insert, update, delete on storage.objects to anon, authenticated, service_role;
grant select, update on storage.buckets to anon, authenticated, service_role;
create function storage.foldername(name text) returns text[] language plpgsql immutable as $$
declare partes text[];
begin
  partes := string_to_array(name, '/');
  return partes[1:array_length(partes, 1) - 1];
end $$;

-- Ayudas de prueba (esquema `t`).
create schema t;
grant usage on schema t to public;
create table t.codigos (clave text primary key, valor text);
grant all on t.codigos to public;

create function t.uid(n int) returns uuid language sql immutable
as $$ select ('00000000-0000-0000-0000-' || lpad(n::text, 12, '0'))::uuid $$;

create function t.como(n int) returns void language plpgsql as $$
begin
  execute 'reset role';
  perform set_config('request.jwt.claim.sub', t.uid(n)::text, false);
  execute 'set role authenticated';
end $$;

create function t.anonimo() returns void language plpgsql as $$
begin
  execute 'reset role';
  perform set_config('request.jwt.claim.sub', '', false);
  execute 'set role anon';
end $$;

create function t.admin() returns void language plpgsql as $$
begin
  execute 'reset role';
  perform set_config('request.jwt.claim.sub', '', false);
end $$;

create function t.afirma(cond boolean, msg text) returns void language plpgsql as $$
begin
  if cond is not true then raise exception 'FALLO: %', msg; end if;
end $$;

-- La consulta debe fallar y el mensaje de error debe contener el patrón (sin distinguir mayúsculas).
create function t.falla(consulta text, patron text) returns void language plpgsql as $$
begin
  begin
    execute consulta;
  exception when others then
    if sqlerrm ilike '%' || patron || '%' then return; end if;
    raise exception 'FALLO: "%" falló con otro error: %', consulta, sqlerrm;
  end;
  raise exception 'FALLO: "%" debía fallar con "%" y no falló', consulta, patron;
end $$;

create function t.n(consulta text) returns bigint language plpgsql as $$
declare r bigint;
begin
  execute format('select count(*) from (%s) q', consulta) into r;
  return r;
end $$;

grant execute on all functions in schema t to public;
```

// Pruebas de la base de datos en un Postgres desechable (Docker) que imita a Supabase.
// Uso: npm run probar:sql [-- filtro]   (filtro: parte del nombre del fichero de prueba)
import { spawnSync } from 'node:child_process';
import { readdirSync, readFileSync, existsSync } from 'node:fs';
import { setTimeout as espera } from 'node:timers/promises';
import { fileURLToPath } from 'node:url';
import path from 'node:path';

const RAIZ = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
const CONT = 'setas-sql-test';
const IMAGEN = 'postgres:17-alpine';

const docker = (args, input) => spawnSync('docker', args, { input, encoding: 'utf8', maxBuffer: 64 * 1024 * 1024 });
const psql = (bd, sql) => docker(['exec', '-i', CONT, 'psql', '-X', '-q', '-v', 'ON_ERROR_STOP=1', '-U', 'postgres', '-d', bd], sql);
const leer = (ruta) => readFileSync(path.join(RAIZ, ruta), 'utf8');
const lista = (dir) => (existsSync(path.join(RAIZ, dir)) ? readdirSync(path.join(RAIZ, dir)).sort().map((f) => `${dir}/${f}`) : []);

// La migración original (con las políticas abiertas), las de cuentas/grupos/compartir y las pendientes. (Las demás migraciones del proyecto necesitan extensiones de Supabase que este entorno no tiene.)
const migraciones = () => [
  'supabase/migrations/20261001000000_setas.sql',
  ...lista('supabase/migrations').filter((f) => /_(cuentas|grupos|compartir).sql$/.test(f)),
  ...lista('supabase/pendientes'),
];

const filtro = process.argv[2];
if (docker(['info']).status !== 0) {
  console.error('Docker no está en marcha: abre Docker Desktop y vuelve a probar.');
  process.exit(2);
}
docker(['rm', '-f', CONT]);
const arranque = docker(['run', '-d', '--rm', '--name', CONT, '-e', 'POSTGRES_PASSWORD=x', IMAGEN]);
if (arranque.status !== 0) { console.error(arranque.stderr); process.exit(2); }

try {
  for (let i = 0; i < 90; i++) {   // la imagen reinicia el servidor tras inicializarse: hay que esperar dos «ready»
    const log = docker(['logs', CONT]);
    if (((`${log.stdout}${log.stderr}`).match(/ready to accept connections/g) ?? []).length >= 2) break;
    await espera(1000);
  }
  const crear = psql('postgres', 'create database plantilla');
  if (crear.status !== 0) throw new Error(`No se pudo crear la plantilla: ${crear.stderr}`);
  for (const f of ['tests/sql/arranque.sql', ...migraciones()]) {
    const p = psql('plantilla', leer(f));
    if (p.status !== 0) throw new Error(`${f}:\n${p.stderr}`);
  }
  let fallos = 0, total = 0;
  const pruebas = readdirSync(path.join(RAIZ, 'tests/sql')).filter((n) => n.endsWith('.test.sql') && (!filtro || n.includes(filtro))).sort();
  for (const f of pruebas) {
    total++;
    const bd = `t_${f.replace(/\W/g, '_')}`;
    const c = psql('postgres', `create database ${bd} template plantilla`);
    if (c.status !== 0) throw new Error(`No se pudo crear ${bd}: ${c.stderr}`);
    const p = psql(bd, leer(`tests/sql/${f}`));
    if (p.status === 0) console.log(`✔ ${f}`);
    else { fallos++; console.log(`✘ ${f}\n${p.stderr}`); }
  }
  console.log(`\n${total - fallos}/${total} ficheros de prueba SQL correctos`);
  process.exitCode = fallos || !total ? 1 : 0;
} catch (e) {
  console.error(e.message);
  process.exitCode = 1;
} finally {
  docker(['rm', '-f', CONT]);
}
```

-- Cuentas: perfil, código de recuperación, traspaso a otra sesión y límite de intentos.
select t.como(1);
do $$
declare c text;
begin
  c := public.crear_perfil('  Ana ');
  insert into t.codigos values ('ana', c);
  perform t.afirma(char_length(c) = 16, 'el código de recuperación tiene 16 caracteres');

-- Cuentas anónimas con perfil y código de recuperación (docs/superpowers/specs/2026-10-02-grupos-design.md §2).
-- Cada dispositivo tiene una sesión anónima de Supabase (auth.uid()); el perfil le pone nombre y un código de
-- recuperación (solo se guarda su hash) con el que otra sesión puede quedarse con la cuenta.

create table public.perfiles (
  id uuid primary key,
  nombre text not null check (char_length(btrim(nombre)) between 1 and 40),
  hash_recuperacion text not null unique,
  creado timestamptz not null default now()
);
alter table public.perfiles enable row level security;
revoke all on public.perfiles from anon, authenticated;
grant select (id, nombre, creado) on public.perfiles to authenticated;   -- el hash no se lee desde la API
create policy "perfil propio: ver" on public.perfiles for select to authenticated using (id = auth.uid());

-- Fallos de «código» (recuperar cuenta, unirse a un grupo) para limitar la fuerza bruta.
create table public.intentos_codigo (
  id bigserial primary key,
  tipo text not null,
  uid uuid,
  ip text,
  momento timestamptz not null default now()
);
create index on public.intentos_codigo (momento);
alter table public.intentos_codigo enable row level security;
revoke all on public.intentos_codigo from anon, authenticated;

-- ---------- Funciones internas ----------
create function public.ip_cliente() returns text language sql stable as $$
  select nullif(split_part(coalesce((nullif(current_setting('request.headers', true), '')::json) ->> 'x-forwarded-for', ''), ',', 1), '')
$$;

-- Texto aleatorio en Crockford base32 (0-9 A-Z sin I L O U): 5 bits por carácter, sin sesgo.
create function public.codigo_aleatorio(p_largo int) returns text
language plpgsql volatile set search_path = public, extensions as $$
declare
  alfabeto constant text := '0123456789ABCDEFGHJKMNPQRSTVWXYZ';
  b bytea := gen_random_bytes(p_largo);
  r text := '';
  i int;
begin
  for i in 0 .. p_largo - 1 loop
    r := r || substr(alfabeto, (get_byte(b, i) & 31) + 1, 1);
  end loop;
  return r;
end $$;

-- Quita separadores y unifica lo que se confunde al teclear (O→0, I y L→1).
create function public.normalizar_codigo(p text) returns text language sql immutable as $$
  select translate(upper(regexp_replace(coalesce(p, ''), '[\s-]', '', 'g')), 'OIL', '011')
$$;

-- Con ~80 bits de entropía basta un SHA-256 sin sal (y permite buscar por igualdad).
create function public.hash_codigo(p text) returns text language sql immutable set search_path = public, extensions as $$
  select encode(extensions.digest(public.normalizar_codigo(p), 'sha256'), 'hex')
$$;

create function public.registrar_fallo(p_tipo text) returns void
language plpgsql security definer set search_path = public as $$
begin
  insert into intentos_codigo (tipo, uid, ip) values (p_tipo, auth.uid(), public.ip_cliente());
end $$;

create function public.limitar_intentos(p_tipo text, p_max int default 10, p_ventana interval default '15 minutes') returns void
language plpgsql security definer set search_path = public as $$
declare n int;
begin
  select count(*) into n from intentos_codigo
   where tipo = p_tipo and momento > now() - p_ventana
     and (uid = auth.uid() or (ip is not null and ip = public.ip_cliente()));
  if n >= p_max then raise exception 'demasiados_intentos'; end if;
end $$;

-- ---------- API ----------
create function public.crear_perfil(p_nombre text) returns text
language plpgsql security definer set search_path = public, extensions as $$
declare codigo text;
begin
  if auth.uid() is null then raise exception 'sin_sesion'; end if;
  if exists (select 1 from perfiles where id = auth.uid()) then raise exception 'perfil_existente'; end if;
  codigo := public.codigo_aleatorio(16);
  insert into perfiles (id, nombre, hash_recuperacion) values (auth.uid(), btrim(p_nombre), public.hash_codigo(codigo));
  return codigo;
end $$;

create function public.regenerar_recuperacion() returns text
language plpgsql security definer set search_path = public, extensions as $$
declare codigo text;
begin
  codigo := public.codigo_aleatorio(16);
  update perfiles set hash_recuperacion = public.hash_codigo(codigo) where id = auth.uid();
  if not found then raise exception 'sin_perfil'; end if;
  return codigo;
end $$;

create function public.renombrar_perfil(p_nombre text) returns void
language plpgsql security definer set search_path = public as $$
begin
  update perfiles set nombre = btrim(p_nombre) where id = auth.uid();
  if not found then raise exception 'sin_perfil'; end if;
end $$;

-- Llamada desde una sesión NUEVA (sin perfil): se queda con el perfil del código. El resto de tablas (grupos,
-- miembros, salidas) apuntan a perfiles(id) con `on update cascade`, así que todo lo del identificador antiguo pasa
-- al nuevo; el dispositivo antiguo se queda sin perfil.
create function public.recuperar_cuenta(p_codigo text) returns boolean
language plpgsql security definer set search_path = public, extensions as $$
declare viejo uuid;
begin
  if auth.uid() is null then raise exception 'sin_sesion'; end if;
  perform public.limitar_intentos('recuperar', 10, '15 minutes');
  select id into viejo from perfiles where hash_recuperacion = public.hash_codigo(p_codigo);
  if viejo is null then
    perform public.registrar_fallo('recuperar');
    return false;
  end if;
  if viejo = auth.uid() then return true; end if;
  if exists (select 1 from perfiles where id = auth.uid()) then raise exception 'sesion_con_perfil'; end if;
  update perfiles set id = auth.uid() where id = viejo;
  return true;
end $$;

-- ---------- Permisos ----------
revoke execute on function public.crear_perfil(text), public.regenerar_recuperacion(),
  public.renombrar_perfil(text), public.recuperar_cuenta(text) from public, anon;
revoke execute on function public.ip_cliente(), public.codigo_aleatorio(int), public.normalizar_codigo(text),
  public.hash_codigo(text), public.registrar_fallo(text), public.limitar_intentos(text, int, interval)
  from public, anon, authenticated;
```

-- Grupos de amigos (docs/superpowers/specs/2026-10-02-grupos-design.md §3 y §5).

create function public.max_miembros_grupo() returns int language sql immutable as $$ select 20 $$;

create table public.grupos (
  id uuid primary key default gen_random_uuid(),
  nombre text not null check (char_length(btrim(nombre)) between 1 and 60),
  codigo_invitacion text not null unique,
  creado_por uuid references public.perfiles (id) on update cascade on delete set null,
  creado timestamptz not null default now()
);
create table public.miembros (
  grupo_id uuid not null references public.grupos (id) on delete cascade,
  usuario_id uuid not null references public.perfiles (id) on update cascade on delete cascade,
  rol text not null check (rol in ('admin', 'miembro')),
  alta timestamptz not null default now(),
  primary key (grupo_id, usuario_id)
);
create index on public.miembros (usuario_id);

-- Dueño de cada salida (nulo = salida anterior a las cuentas, sin reclamar) y con qué grupos se comparte.
alter table public.salidas add column usuario_id uuid references public.perfiles (id) on update cascade on delete set null;
create index on public.salidas (usuario_id);
create table public.salida_grupos (
  salida_id uuid not null references public.salidas (id) on delete cascade,
  grupo_id uuid not null references public.grupos (id) on delete cascade,
  ubicacion_exacta boolean not null default true,
  primary key (salida_id, grupo_id)
);
create index on public.salida_grupos (grupo_id);

-- ---------- Comprobaciones (security definer: no pasan por RLS, así que no hay recursión) ----------
create function public.es_miembro(p_grupo uuid) returns boolean
language sql stable security definer set search_path = public as $$
  select exists (select 1 from miembros where grupo_id = p_grupo and usuario_id = auth.uid())
$$;
create function public.es_admin(p_grupo uuid) returns boolean
language sql stable security definer set search_path = public as $$
  select exists (select 1 from miembros where grupo_id = p_grupo and usuario_id = auth.uid() and rol = 'admin')
$$;

alter table public.grupos enable row level security;
alter table public.miembros enable row level security;
alter table public.salida_grupos enable row level security;
revoke all on public.grupos, public.miembros, public.salida_grupos from anon, authenticated;
grant select on public.grupos, public.miembros, public.salida_grupos to authenticated;
create policy "grupos: los míos" on public.grupos for select to authenticated using (public.es_miembro(id));
create policy "miembros: de mis grupos" on public.miembros for select to authenticated using (public.es_miembro(grupo_id));
create policy "salida_grupos: del dueño" on public.salida_grupos for select to authenticated
  using (exists (select 1 from public.salidas s where s.id = salida_id and s.usuario_id = auth.uid()));

-- ---------- API ----------
create function public.crear_grupo(p_nombre text) returns table (grupo_id uuid, codigo text)
language plpgsql security definer set search_path = public, extensions as $$
declare g uuid; c text; intento int := 0;
begin
  if not exists (select 1 from perfiles where id = auth.uid()) then raise exception 'sin_perfil'; end if;
  loop
    c := public.codigo_aleatorio(8);
    begin
      insert into grupos (nombre, codigo_invitacion, creado_por) values (btrim(p_nombre), c, auth.uid()) returning id into g;
      exit;
    exception when unique_violation then
      intento := intento + 1;
      if intento > 5 then raise; end if;
    end;
  end loop;
  insert into miembros (grupo_id, usuario_id, rol) values (g, auth.uid(), 'admin');
  return query select g, c;
end $$;

create function public.unirse_grupo(p_codigo text) returns uuid
language plpgsql security definer set search_path = public, extensions as $$
declare g uuid;
begin
  if not exists (select 1 from perfiles where id = auth.uid()) then raise exception 'sin_perfil'; end if;
  perform public.limitar_intentos('unirse', 10, '15 minutes');
  select id into g from grupos where codigo_invitacion = public.normalizar_codigo(p_codigo);
  if g is null then
    perform public.registrar_fallo('unirse');
    return null;
  end if;
  if exists (select 1 from miembros where grupo_id = g and usuario_id = auth.uid()) then return g; end if;
  if (select count(*) from miembros where grupo_id = g) >= public.max_miembros_grupo() then raise exception 'grupo_lleno'; end if;
  insert into miembros (grupo_id, usuario_id, rol) values (g, auth.uid(), 'miembro');
  return g;
end $$;

create function public.regenerar_codigo(p_grupo uuid) returns text
language plpgsql security definer set search_path = public, extensions as $$
declare c text;
begin
  if not public.es_admin(p_grupo) then raise exception 'no_admin'; end if;
  c := public.codigo_aleatorio(8);
  update grupos set codigo_invitacion = c where id = p_grupo;
  return c;
end $$;

create function public.renombrar_grupo(p_grupo uuid, p_nombre text) returns void
language plpgsql security definer set search_path = public as $$
begin
  if not public.es_admin(p_grupo) then raise exception 'no_admin'; end if;
  update grupos set nombre = btrim(p_nombre) where id = p_grupo;
end $$;

create function public.hacer_admin(p_grupo uuid, p_usuario uuid) returns void
language plpgsql security definer set search_path = public as $$
begin
  if not public.es_admin(p_grupo) then raise exception 'no_admin'; end if;
  update miembros set rol = 'admin' where grupo_id = p_grupo and usuario_id = p_usuario;
  if not found then raise exception 'no_miembro'; end if;
end $$;

-- Lo que un miembro tenía compartido en el grupo deja de verse al irse o ser expulsado.
create function public.expulsar_miembro(p_grupo uuid, p_usuario uuid) returns void
language plpgsql security definer set search_path = public as $$
begin
  if not public.es_admin(p_grupo) then raise exception 'no_admin'; end if;
  if p_usuario = auth.uid() then raise exception 'usa_salir'; end if;
  delete from salida_grupos where grupo_id = p_grupo and salida_id in (select id from salidas where usuario_id = p_usuario);
  delete from miembros where grupo_id = p_grupo and usuario_id = p_usuario;
end $$;

create function public.salir_grupo(p_grupo uuid) returns void
language plpgsql security definer set search_path = public as $$
declare otros int; admins int;
begin
  if not public.es_miembro(p_grupo) then raise exception 'no_miembro'; end if;
  select count(*) into otros from miembros where grupo_id = p_grupo and usuario_id <> auth.uid();
  if otros = 0 then
    delete from grupos where id = p_grupo;   -- el último en salir apaga la luz (cascada a miembros y salida_grupos)
    return;
  end if;
  select count(*) into admins from miembros where grupo_id = p_grupo and rol = 'admin' and usuario_id <> auth.uid();
  if admins = 0 then raise exception 'ultimo_admin'; end if;
  delete from salida_grupos where grupo_id = p_grupo and salida_id in (select id from salidas where usuario_id = auth.uid());
  delete from miembros where grupo_id = p_grupo and usuario_id = auth.uid();
end $$;

create function public.borrar_grupo(p_grupo uuid) returns void
language plpgsql security definer set search_path = public as $$
begin
  if not public.es_admin(p_grupo) then raise exception 'no_admin'; end if;
  delete from grupos where id = p_grupo;
end $$;

-- Visibilidad de las salidas (docs/superpowers/specs/2026-10-02-grupos-design.md §4 y §5).
-- Las políticas «abiertas» de la migración original siguen activas hasta la migración de cierre
-- (supabase/pendientes/20261006000000_cerrar_acceso_abierto.sql): las políticas de abajo ya son las definitivas.

create policy "salidas: dueño" on public.salidas for all to authenticated
  using (usuario_id = auth.uid()) with check (usuario_id = auth.uid());
create policy "fotos: dueño de la salida" on public.fotos for all to authenticated
  using (exists (select 1 from public.salidas s where s.id = salida_id and s.usuario_id = auth.uid()))
  with check (exists (select 1 from public.salidas s where s.id = salida_id and s.usuario_id = auth.uid()));

-- Reemplaza con qué grupos se comparte una salida (conjunto completo, atómico).
create function public.compartir_salida(p_salida uuid, p_grupos jsonb) returns void
language plpgsql security definer set search_path = public as $$
begin
  if not exists (select 1 from salidas where id = p_salida and usuario_id = auth.uid()) then raise exception 'no_es_tuya'; end if;
  if exists (
    select 1 from jsonb_to_recordset(p_grupos) as x (grupo_id uuid, ubicacion_exacta boolean)
    where x.grupo_id is null or not public.es_miembro(x.grupo_id)
  ) then raise exception 'no_miembro'; end if;
  delete from salida_grupos sg
   where sg.salida_id = p_salida
     and not exists (select 1 from jsonb_to_recordset(p_grupos) as x (grupo_id uuid, ubicacion_exacta boolean) where x.grupo_id = sg.grupo_id);
  insert into salida_grupos (salida_id, grupo_id, ubicacion_exacta)
    select p_salida, x.grupo_id, coalesce(x.ubicacion_exacta, true)
    from jsonb_to_recordset(p_grupos) as x (grupo_id uuid, ubicacion_exacta boolean)
  on conflict (salida_id, grupo_id) do update set ubicacion_exacta = excluded.ubicacion_exacta;
end $$;

-- Lo que ve un miembro: sin coordenadas, sin meteo y sin el punto del índice cuando se compartió «solo la zona».
-- (Una policy no puede ocultar columnas: por eso se lee por función y no por la tabla.)
create function public.salidas_del_grupo(p_grupo uuid)
returns table (id uuid, usuario_id uuid, autor text, fecha date, zona_id text, lat double precision, lon double precision,
  ubicacion_exacta boolean, especies jsonb, notas text, meteo jsonb, indice jsonb, fotos jsonb)
language plpgsql stable security definer set search_path = public as $$
begin
  if not public.es_miembro(p_grupo) then raise exception 'no_miembro'; end if;
  return query
    select s.id, s.usuario_id, p.nombre, s.fecha, s.zona_id,
           case when sg.ubicacion_exacta then s.lat end,
           case when sg.ubicacion_exacta then s.lon end,
           sg.ubicacion_exacta, s.especies, s.notas,
           case when sg.ubicacion_exacta then s.meteo end,
           case when sg.ubicacion_exacta then s.indice else s.indice - 'punto' end,
           coalesce((select jsonb_agg(jsonb_build_object('ruta', f.ruta, 'ancho', f.ancho, 'alto', f.alto) order by f.ruta)
                     from fotos f where f.salida_id = s.id), '[]'::jsonb)
    from salida_grupos sg
    join salidas s on s.id = sg.salida_id
    join perfiles p on p.id = s.usuario_id
    where sg.grupo_id = p_grupo
    order by s.fecha desc, s.creado desc;
end $$;

-- Reclamo de las salidas anteriores a las cuentas (usuario_id nulo), por el nombre de autor que llevaban.
create function public.salidas_sin_dueno() returns table (autor text, n bigint)
language sql stable security definer set search_path = public as $$
  select coalesce(s.autor, ''), count(*) from salidas s where s.usuario_id is null group by coalesce(s.autor, '') order by 1
$$;

create function public.reclamar_salidas(p_autor text) returns integer
language plpgsql security definer set search_path = public as $$
declare n int;
begin
  if not exists (select 1 from perfiles where id = auth.uid()) then raise exception 'sin_perfil'; end if;
  update salidas set usuario_id = auth.uid() where usuario_id is null and coalesce(autor, '') = coalesce(p_autor, '');
  get diagnostics n = row_count;
  return n;
end $$;

revoke execute on function public.compartir_salida(uuid, jsonb), public.salidas_del_grupo(uuid),
  public.salidas_sin_dueno(), public.reclamar_salidas(text) from public, anon;
```

  select case when split_part(p_ruta, '/', 1) ~ '^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$'
              then split_part(p_ruta, '/', 1)::uuid end
$$;
create function public.es_mi_salida(p_salida uuid) returns boolean
language sql stable security definer set search_path = public as $$
  select exists (select 1 from salidas where id = p_salida and usuario_id = auth.uid())
$$;
create function public.puede_ver_foto(p_ruta text) returns boolean
language sql stable security definer set search_path = public as $$
  select exists (
    select 1 from salidas s
    where s.id = public.ruta_salida_id(p_ruta)
      and (s.usuario_id = auth.uid()
           or exists (select 1 from salida_grupos sg join miembros m on m.grupo_id = sg.grupo_id
                      where sg.salida_id = s.id and m.usuario_id = auth.uid()))
  )
$$;
revoke execute on function public.ruta_salida_id(text), public.es_mi_salida(uuid), public.puede_ver_foto(text) from public, anon;

create policy "fotos: ver" on storage.objects for select to authenticated

// Cuenta de este dispositivo: sesión anónima de Supabase, perfil y código de recuperación.
// Todo con el cliente inyectado ({ supabase }) para poder probarlo sin red.
const ALFABETO = '0123456789ABCDEFGHJKMNPQRSTVWXYZ';   // Crockford base32: sin I, L, O, U

// Quita separadores y unifica lo que se confunde al teclear (O→0, I y L→1), igual que el servidor.
export const normalizarCodigo = (t) => String(t ?? '').toUpperCase().replace(/[\s-]/g, '').replace(/O/g, '0').replace(/[IL]/g, '1');
export const formatearCodigo = (c, bloque = 4) => normalizarCodigo(c).match(new RegExp(`.{1,${bloque}}`, 'g'))?.join('-') ?? '';
export function codigoRecuperacionValido(t) {
  const n = normalizarCodigo(t);
  return n.length === 16 && [...n].every((c) => ALFABETO.includes(c));
}

// Una sola entrada anónima aunque varias partes de la app la pidan a la vez.
let enCurso = null;
export function asegurarSesion({ supabase }) {
  enCurso ??= (async () => {
    const { data } = await supabase.auth.getSession();
    if (data?.session) return data.session.user.id;
    const r = await supabase.auth.signInAnonymously();
    if (r.error) throw r.error;
    return r.data.user.id;
  })().finally(() => { enCurso = null; });
  return enCurso;
}

// `null` solo si el perfil NO existe; un fallo de red se propaga (no es lo mismo: crear otro perfil duplicaría la cuenta).
export async function cargarPerfil({ supabase }) {
  const uid = await asegurarSesion({ supabase });
  const { data, error } = await supabase.from('perfiles').select('id, nombre').eq('id', uid).maybeSingle();
  if (error) throw error;
  return data ? { id: data.id, nombre: data.nombre } : null;
}

export async function crearPerfil(nombre, { supabase }) {
  await asegurarSesion({ supabase });
  const { data, error } = await supabase.rpc('crear_perfil', { p_nombre: nombre });
  if (error) throw error;
  return formatearCodigo(data);
}

export async function regenerarRecuperacion({ supabase }) {
  await asegurarSesion({ supabase });
  const { data, error } = await supabase.rpc('regenerar_recuperacion');
  if (error) throw error;
  return formatearCodigo(data);
}

export async function renombrarPerfil(nombre, { supabase }) {
  await asegurarSesion({ supabase });
  const { error } = await supabase.rpc('renombrar_perfil', { p_nombre: nombre });
  if (error) throw error;
}

// true = esta sesión es ahora la dueña de la cuenta; false = el código no existe o está mal escrito.
export async function recuperarCuenta(codigo, { supabase }) {
  if (!codigoRecuperacionValido(codigo)) return false;
  await asegurarSesion({ supabase });
  const { data, error } = await supabase.rpc('recuperar_cuenta', { p_codigo: normalizarCodigo(codigo) });
  if (error) throw error;
  return data === true;
}

// Idempotente de verdad: el `id` del borrador (uuid) es la clave primaria de la salida y el alta ignora duplicados,
// así que una respuesta perdida no crea una segunda salida. Tras el alta guarda `remotoId` (vía `persistir`) y las
// fotos ya subidas (`fotosSubidas`) no se repiten; la fila de `fotos` se comprueba antes de insertarla.
// `usuarioId` (dueño) viene de la sesión en el momento de subir, así un borrador sobrevive a recuperar la cuenta.
// `b.grupos` = [{ grupo_id, ubicacion_exacta }]: se comparte una sola vez (`compartida`); si ya no eres miembro del
// grupo, la salida se queda privada en vez de atascar la cola.
export async function crearSalida(b, { supabase, persistir, almacenFotos = null, usuarioId = null }) {
  const marcar = (cambios) => { Object.assign(b, cambios); persistir?.(b); };
  if (!b.remotoId) {
    const fila = Object.fromEntries(Object.entries(b).filter(([k]) => COLUMNAS.includes(k)));
    if (usuarioId) fila.usuario_id = usuarioId;
    const { error } = await supabase.from('salidas').upsert({ ...fila, id: b.id }, { onConflict: 'id', ignoreDuplicates: true });
    if (error) throw error;
    marcar({ remotoId: b.id });
  }
  if (b.grupos?.length && !b.compartida) {
    const { error } = await supabase.rpc('compartir_salida', { p_salida: b.remotoId, p_grupos: b.grupos });
    if (error && !/no_miembro/.test(error.message ?? '')) throw error;
    marcar({ compartida: true });
  }
  const fotos = b.fotos ?? [];
  if (fotos.length && (b.fotosSubidas ?? 0) < fotos.length) {
    const previas = await supabase.from('fotos').select('ruta').eq('salida_id', b.remotoId);
    if (previas.error) throw previas.error;
    const hechas = new Set((previas.data ?? []).map((f) => f.ruta));
    for (let k = b.fotosSubidas ?? 0; k < fotos.length; k++) {
      const f = fotos[k];
      const ruta = `${b.remotoId}/${k + 1}.jpg`;
      let blob;
      if (f.clave) {
        blob = await almacenFotos?.get(f.clave);
        if (!blob) throw new Error('Falta una foto guardada en el móvil');
      } else blob = await (await fetch(f.dataUrl)).blob();
      const up = await supabase.storage.from(BUCKET).upload(ruta, blob, { contentType: 'image/jpeg', upsert: true });
      if (up.error) throw up.error;
      if (!hechas.has(ruta)) {
        const ins = await supabase.from('fotos').insert({ salida_id: b.remotoId, ruta, ancho: f.ancho, alto: f.alto });
        if (ins.error) throw ins.error;
      }
      marcar({ fotosSubidas: k + 1 });
    }
  }
  for (const f of fotos) if (f.clave) await almacenFotos?.borrar(f.clave).catch(() => {});
  return b.remotoId;
}
